Firebaseの設定方法（GitHub Pagesで公開する人向け）
  1. Firebaseコンソールでプロジェクトを作成します。
  2. 「構築 → Realtime Database」でデータベースを作成します（無料のSparkプランでOK）。
  3. プロジェクト設定 → 「マイアプリ」でWebアプリ（</>）を追加すると、firebaseConfig が表示されます。
  4. このHTMLファイル冒頭のスクリプトにある firebaseConfig のプレースホルダーを、自分の値に書き換えて保存します。
  5. Realtime Databaseの「ルール」は、大会期間中だけ読み書きできる設定にしてください（例：テストモード）。終わったらルールを閉じるのがおすすめです。
  6. 書き換えたHTMLをGitHub Pagesに公開すれば、全員のスマホからリアルタイム対戦できます。
{
  "rules": {
    "players": { ".read": true, ".write": true },
    "meta": { ".read": true, ".write": true },
    "match": { ".read": true, ".write": true }
  }
}

一斉スタート対戦では match ノード（status / startAt / round）で全員のカウントダウンを同期し、対戦中は各プレイヤーの liveScore / liveRound、終了後は lastScore / lastRound を使って順位を表示します。

※ 上のルールは誰でも読み書きできる大会用の簡易設定です。公開期間が終わったら削除または制限してください。
